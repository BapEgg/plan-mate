# PlanMate Frontend

React, TypeScript, Vite 기반 PlanMate 프론트엔드 모듈이다.

## Requirements

- Node.js 20.19 이상 또는 22.12 이상
- npm

## Commands

```bash
npm install
npm run dev
npm run build
npm run preview
npm run lint
```

## Project Structure

```text
frontend/
├─ public/
├─ src/
│  ├─ App.tsx
│  ├─ App.css
│  ├─ index.css
│  └─ main.tsx
├─ index.html
├─ package.json
├─ tsconfig.json
└─ vite.config.ts
```
